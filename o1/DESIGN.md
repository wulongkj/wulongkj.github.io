# 高并发骨架屏导航搜索站 - 设计文档

> 目录：`/workspace/o1/`
> 状态：设计先行，随后实现

## 1. 需求分析

| 需求 | 说明 |
|------|------|
| 完整 HTML 搜索页 | 纯前端骨架屏交互，不依赖重框架 |
| 高并发 | 后端内存缓存 + 前端防抖/竞态控制，支撑大量并发访问 |
| 无输入态 | 仅显示输入框与简单布局装饰，页面极简 |
| 全量 JSON 搜索 | 搜索时遍历 `data/` 下全部 JSON 文件 |
| 跳转页面 | 点击结果先进入中转跳转页 |
| 广告位 | 跳转页预留文字广告位 + 图片广告位 |
| 演示地址 | 部署后提供可访问的预览链接 |
| 版权安全 | 只借鉴开源项目的交互/视觉思路，代码全部原创编写 |

## 2. 架构设计

```
┌────────────┐      /api/search?q=xxx       ┌─────────────────────┐
│  index.html │ ───────────────────────────► │      server.js      │
│  (骨架屏)   │                              │  静态服务 + 搜索 API  │
└────────────┘ ◄─────────────────────────── └─────────┬───────────┘
        │                                              │ 启动时全量加载
        │ 点击结果                                      ▼
        ▼                                        ┌─────────────┐
┌────────────┐      /api/ads                    │ data/*.json │
│  jump.html  │ ──────────────────────────────► │ (内存缓存)   │
│ (广告位+跳转)│ ◄────────────────────────────── └─────────────┘
└────────────┘
```

### 2.1 高并发策略

1. **内存搜索索引**：服务启动时将 `data/` 下全部 JSON（排除 `ads.json`）读入内存，把每条的 `name + url + desc + tags` 拼成小写检索串，搜索时纯内存过滤，单次查询 O(N)。
2. **文件变更感知**：记录每个文件的 `mtime`，请求时检测变化，改动后自动重新加载，无需重启。
3. **前端防抖**：输入 180ms 防抖，只在停顿后发起请求。
4. **竞态控制**：请求带递增序号，只渲染最新一次结果，丢弃过期响应。
5. **骨架屏即时反馈**：请求未返回时立即渲染骨架卡片占位，避免白屏抖动。

### 2.2 页面交互状态机

```
                输入为空                        输入非空
   ┌─────────────────────────┐   oninput   ┌─────────────────────────┐
   │   空态：仅输入框 + 装饰   │ ───────────► │   请求中：骨架屏卡片     │
   └─────────────────────────┘             └───────────┬─────────────┘
         ▲ 清空输入                                    │ 请求返回
         │                                            ▼
         │                                 ┌─────────────────────────┐
         └──────────────────────────────── │   结果态：真实卡片列表    │
                清空输入                    └─────────────────────────┘
```

## 3. 页面设计

### 3.1 index.html（搜索主页）

- 视觉：深蓝紫渐变背景 + 点缀圆形光斑，毛玻璃输入框。
- 空态布局（垂直居中）：
  - 顶部：站名 Logo + 副标题
  - 中部：搜索输入框（带放大镜 SVG 图标 + 清除按钮）
  - 底部：极简装饰元素与版权文案
- 输入态：
  - 输入框收缩到页面上方，结果区展示卡片网格。
  - 骨架屏卡片：左侧圆形图标占位 + 右侧两条文字条（CSS shimmer 动画）。
  - 结果卡片：首字母图标（本地生成，无需第三方）、名称、描述、标签徽章。
- 交互细节：
  - `Esc` 清空输入回到空态；`Enter` 立即搜索。
  - 每次新关键词触发一次骨架屏刷新，旧结果淡出。

### 3.2 jump.html（跳转中转页）

- 功能：展示目标网站名称/域名，倒计时（5s）后自动跳转，也可点击立即跳转。
- 广告位（从 `data/ads.json` 读取）：
  - **图片广告位**：页面顶部横幅（响应式，横向大图，可关闭）。
  - **文字广告位**：目标信息下方，两条文字链。
  - 无广告配置时隐藏广告区域，不影响主功能。
- 安全：目标 URL 经 `encodeURIComponent` 传输，页面仅信任 http/https 协议，防伪协议注入。

### 3.3 数据格式

```json
// data/*.json 网站数据（数组）
[{ "name": "百度", "url": "https://www.baidu.com", "desc": "全球中文搜索引擎", "tags": ["搜索","中国"] }]

// data/ads.json 广告配置
{
  "image": [{ "title": "横幅广告", "url": "https://target.com", "img": "/assets/ad-banner.png" }],
  "text":  [{ "title": "文字广告", "url": "https://target.com", "text": "推广文案" }]
}
```
